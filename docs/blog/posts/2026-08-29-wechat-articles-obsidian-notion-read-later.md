# 把微信公众号文章自动同步进 Obsidian/Notion：稍后读与个人知识库搭建法

刷微信时收藏的文章，十篇里有九篇再也不会被打开。收藏夹按时间倒序排列，越早收藏的越沉底；想找某篇讲过某个方法的文章,只能凭模糊的记忆去收藏夹里翻,翻不到就等于没收藏过。

问题不在于「记性差」,而在于收藏本身是一次性动作:文章被存进一个不可检索、不可关联、不能被其他工具读取的黑盒里。真正需要的是持续沉淀——关注的号、认可的作者,发的每一篇文章都能自动进入自己的知识库,和已有的笔记互相链接、共同检索,而不是散落在聊天记录和收藏夹里。

对经常读公众号获取信息的人来说（无论是关注的行业作者、专栏博主还是产品资讯号），更合理的方式是把「稍后读」变成一条自动化管道：文章一发布，就以结构化数据的形式流入自己的笔记系统。

## 手动收藏的局限

- **不可检索**：微信收藏夹只能按公众号或时间浏览，无法跨文章做关键词全文搜索。
- **不可关联**：收藏的文章是孤立的记录，无法像笔记软件里的双向链接那样与已有知识建立联系。
- **依赖客户端**：只能在微信内查看，无法用自己惯用的笔记工具（Obsidian、Notion、Logseq 等）统一管理、打标签、加批注。
- **格式受限**：转发或截图会丢失原文排版和链接，复制文本又常常夹杂图片占位符和乱码。

这些限制的根源是一样的：公众号文章从始至终都以「一次性内容」的形态存在，没有被当作可编程、可迁移的数据。

## 解决思路：让文章以数据形式流入知识库

[Mp2RSS](https://mp2rss.bugcode.dev) 是一个微信公众号文章数据服务：贴入任意一篇文章的链接（`https://mp.weixin.qq.com/s?...`），即可订阅它所属的整个公众号；此后该号发布的每一篇新文章都会被持续收录，并以带 **Markdown 正文**的结构化数据形式交付，从发文到数据可见平均 2–3 小时。使用时无需微信账号，GitHub / Google 登录即可。

有了 Markdown 正文和标准化的 Feed，公众号文章就能像任何其他网页内容一样，被笔记工具订阅、抓取、归档，而不再是只能停留在微信里的孤岛。

## 落地步骤

### 第一步：订阅关注的公众号

把想长期跟踪的公众号（专栏作者、行业媒体、产品资讯号）逐个订阅进来。找到该号任意一篇文章的链接贴入 Mp2RSS 控制台即可完成，具体操作参见[订阅管理指引](/guide/subscription)。需要注意的是首次订阅不回溯历史文章，只从订阅时刻起收录新内容，所以想长期沉淀的号建议尽早订阅。

### 第二步：接入 RSS 阅读器或稍后读工具

Mp2RSS 为每个订阅提供 RSS 2.0 / Atom 1.0 / JSON Feed 1.1 格式的聚合 Feed，可以直接粘贴进任意支持订阅源的稍后读或阅读工具。这一步不需要写代码：把 Feed 地址加入常用的 RSS 阅读器,或者接入支持 RSS 转发的自动化工具（如 n8n、Zapier）,让新文章自动出现在收件箱或指定频道里。

### 第三步：自动写入 Obsidian / Notion

如果希望文章直接沉淀为笔记而不只是「看到」，可以用 [Open API](/api/) 拉取文章数据，写入本地或云端的笔记库：

```bash
curl "https://mp2rss.bugcode.dev/open-api/subscriptions/{mpId}/articles" \
  -H "Authorization: Bearer {feed_key}"
```

返回的每篇文章都带有标题、发布时间与 Markdown 正文，可以直接落盘为 Obsidian Vault 里的一个 `.md` 文件（文件名用标题或发布日期），也可以调用 Notion 的页面创建接口把正文写成一个新页面。由于正文本身就是 Markdown，两边的格式转换几乎不需要额外处理，代码块、链接、标题层级都能原样保留。

对个人用户来说，这类同步脚本通常几十行就能跑起来，用系统的定时任务（cron / 计划任务）每天跑一次即可，不需要长期挂在服务器上。

### 第四步：建立检索与关联

文章进入 Obsidian 或 Notion 之后，就能用工具自带的全文搜索、标签和双向链接把它和已有笔记关联起来——读到一篇讲某个方法的文章，可以直接反链到自己之前记录的相关笔记，而不再需要凭记忆去收藏夹里翻找。

## 效果对比

| 维度 | 微信收藏夹 | 同步进个人知识库 |
| ---- | ---- | ---- |
| 检索方式 | 按号 / 按时间浏览 | 全文搜索、标签、双向链接 |
| 可迁移性 | 仅限微信客户端内 | Markdown 文件，可被任意工具读取 |
| 更新方式 | 手动逐篇收藏 | 新文章自动同步，平均 2–3 小时到账 |
| 与已有笔记的关联 | 无 | 可直接反链、加批注 |

## 常见问题

**需要保持微信登录或用手机操作吗？**
不需要。Mp2RSS 使用 GitHub / Google 账号登录，订阅与同步全程不依赖微信客户端或手机端操作。

**只是想简单地在阅读器里刷更新，不想写代码，可以吗？**
可以。把 Mp2RSS 提供的 RSS / JSON Feed 地址粘贴进任意 RSS 阅读器或支持订阅源的工具即可，不需要调用 API。

**能同步订阅之前已经发布的历史文章吗？**
不能。首次订阅只从订阅时刻起收录新文章，不回溯历史，建议对长期关注的号尽早完成订阅。

**除了公众号，还能同步哪些信息源？**
同时支持订阅 X（Twitter）账号，推文与长文同样以结构化数据交付，可以并入同一套同步流程。

**订阅数量有限制吗？**
有档位区分：49 元/月 50 个订阅、99 元/月 100 个、399 元/月 400 个，功能一致，仅上限不同，详见[会员与计费](/guide/membership)。
