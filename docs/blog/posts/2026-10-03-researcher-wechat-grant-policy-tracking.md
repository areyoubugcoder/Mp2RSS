# 高校科研人员如何用公众号追踪科研基金申报政策：避免错过截止期的方法

每年到了国家自然科学基金、社科基金、省部级重点研发计划的申报季，科研人员最怕的不是写本子,而是错过通知本身。申报指南、经费预算调整、材料清单变化，这些信息往往不会发邮件通知到个人，而是第一时间挂在基金委、科技厅、学校科研处的公众号上，隔几天就被新消息顶到历史列表里,很容易错过。

更麻烦的是，这类信息分散在多个账号上：国家级基金委的总口径、省级科技厅的地方配套政策、学校科研处转发的内部补充说明，往往还有二级学院或重点实验室自己发的截止日期提醒。一个课题组成员要同时盯五六个公众号，每个号的更新频率、措辞风格都不一样，很难靠人工每天逐个打开查看，稍微出差或忙于实验几天,就可能错过一个关键节点的变更。

公众号本身也没有提醒机制，关注的号一多，新消息很快被其他账号的推送淹没，更谈不上针对「申报截止时间」这类关键词做主动提醒。等到想起来要交材料，才发现通道已经在三天前关闭，这种情况在课题组里并不少见。

## 解决思路：把政策类公众号变成可追踪的数据源

与其每天手动打开微信逐个翻看，不如把需要关注的政策类公众号变成持续更新的结构化数据，由系统自动采集，人工只在需要时检索或设置关键词筛选。[Mp2RSS](https://mp2rss.bugcode.dev) 提供这样的能力：把任意一篇公众号文章的链接（`https://mp.weixin.qq.com/s?...`）贴进去即可订阅该公众号，此后该号发布的新文章会被持续采集并转换为带 Markdown 正文的结构化数据，从发文到数据可见平均 2–3 小时，不需要用微信账号登录，GitHub 或 Google 账号即可完成授权。

## 落地步骤

### 第一步：梳理需要追踪的政策账号清单

按信息层级列出相关公众号，通常分三类：

- **国家级**：国家自然科学基金委员会、教育部科技司等官方账号；
- **省级 / 行业主管部门**：所在省份科技厅、相关行业主管部委下属公众号；
- **校内**：学校科研处、所在学院或重点实验室的公众号。

同一课题组可以分工认领不同层级的账号，避免重复关注又都漏看的情况。

### 第二步：批量完成订阅

逐个订阅可参考[订阅管理指引](/guide/subscription)。如果需要追踪的账号数量较多，比如同时跟踪多个省份的科技厅公众号做跨地区课题比较，用 [Open API](/api/) 写脚本批量提交效率更高：

```bash
curl -X POST "https://mp2rss.bugcode.dev/open-api/subscriptions" \
  -H "Authorization: Bearer {feed_key}" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://mp.weixin.qq.com/s?__biz=..."}'
```

需要注意，首次订阅不会回溯该账号此前发布的历史文章，只从订阅时刻起持续收录新内容。因此建议在申报季开始前尽早完成订阅,覆盖越早，越不容易漏掉季初发布的指南原文。

### 第三步：定时拉取，关键词过滤出申报相关内容

订阅完成后，定时调用文章列表接口拉取新增文章：

```bash
curl "https://mp2rss.bugcode.dev/open-api/subscriptions/{mpId}/articles" \
  -H "Authorization: Bearer {feed_key}"
```

拿到的正文是 Markdown 格式，可以直接用「申报」「截止」「材料清单」「经费」等关键词做全文匹配，把真正和申报节点相关的文章从一堆日常推送中筛出来，不用逐篇通读。不方便写代码的课题组成员，也可以用 [CLI 工具（mp2rss）](/cli/)，在命令行里完成订阅与拉取，不需要额外开发环境。

### 第四步：接入提醒或日历工具

拉取到的文章数据可以进一步接入自己的提醒机制：比如用关键词命中后触发邮件或企业微信通知，或者把识别出的截止日期写入课题组共享日历。具体的数据接入方式可以参考[快速开始](/guide/quick-start)，把公众号数据当作标准化数据源对接到已有的工具链里，而不是停留在「人工刷新」这一步。

### 第五步：跨年度留存，形成政策变化的对照记录

科研基金的申报细则每年都会有小幅调整，比如经费比例、材料格式要求。把历年抓取到的申报通知按年份归档保存，下一年申报季来临时，可以直接对比往年原文,快速找出哪些条款变了，不用凭记忆猜测。

## 常见问题

**订阅这些政策类公众号需要对方授权吗？**
不需要。Mp2RSS 采集的是公众号公开发布的文章内容，只要拿到该公众号任意一篇文章的链接即可完成订阅，不涉及账号授权。

**能找回订阅之前已经发布的历史申报通知吗？**
不能。首次订阅不会回溯历史文章，只从订阅时刻起持续收录新内容，所以建议在申报季正式开始前就完成订阅。

**课题组几个人可以共用一个账号追踪吗？**
可以，订阅上限按套餐区分：49 元/月 50 个订阅、99 元/月 100 个、399 元/月 400 个，功能权益一致，仅订阅上限不同，详见[会员与计费](/guide/membership)。

**除了公众号，海外合作机构的官方账号也能追踪吗？**
支持订阅 X（Twitter）账号，做国际合作项目或跨境基金申报对比时，可以把中外两类信源并入同一条采集管道统一管理。

**拿到的文章数据是什么格式，方便做关键词检索吗？**
文章正文以 Markdown 格式交付，交付形态还包括 RSS 2.0 / Atom 1.0 / JSON Feed 1.1 / OPML 2.0 以及 Open API，可以直接对接关键词匹配脚本或文本检索工具。
