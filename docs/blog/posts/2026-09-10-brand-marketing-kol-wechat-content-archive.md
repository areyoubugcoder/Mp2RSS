# 品牌营销团队如何归档追踪 KOL 公众号内容：合作评估与投放留痕

品牌营销团队在挑选公众号 KOL 合作时，通常要先看这个号过去发了什么：选题方向是否匹配品牌调性、更新频率是否稳定、有没有发过同类竞品的软文。但公众号历史消息只能在手机端逐条下拉翻看，既没有搜索也没有筛选，想统计一个号过去半年发了多少条广告、多少条纯内容，只能靠人工数条子。

合作确定并投放之后，问题换了一种形式：投放文章发布后，团队需要留存这篇文章的完整内容、发布时间与后续是否被删改，作为合作验收与复盘的凭证。如果只是截图保存，图片里的排版、链接、小程序卡片都会丢失，事后想核对文案原文往往还得重新找链接、重新打开公众号。

跨多个 KOL 同时合作时，这两个问题会叠加：选号阶段要对比十几个候选号的历史内容密度，投放阶段要盯住每个号的发文是否按约定时间上线，复盘阶段要把所有投放文章集中归档比对效果。全靠人工操作，团队要么漏掉细节，要么把大量时间耗在翻页和截图上。

## 人工归档 KOL 内容的三个卡点

1. **选号阶段看不全历史**：公众号历史消息列表加载慢、无法搜索，评估一个号过去的内容风格和商业化密度，只能靠反复下拉翻页人工统计。
2. **投放留痕依赖截图**：投放文章上线后，团队常用截图或转发保存证据，但截图会丢失原文排版与链接，文字内容也无法被检索。
3. **多号并行难以横向比较**：同时和多个 KOL 合作时，需要把不同号的发文节奏、内容类型汇总对比，人工整理成表格的过程繁琐且容易出错。

这三个卡点的共同原因是：公众号内容始终以「网页」而非「数据」的形式存在，无法被搜索、筛选或批量导出。

## 解决思路：把 KOL 公众号内容转成结构化档案

[Mp2RSS](https://mp2rss.bugcode.dev) 提供公众号文章的数据化服务：贴入 KOL 任意一篇文章的链接（`https://mp.weixin.qq.com/s?...`），即可订阅该号，此后该号发布的每一篇新文章都会被持续收录为**带 Markdown 正文的结构化数据**，从发文到数据可见平均 2–3 小时。使用时不需要微信账号，用 GitHub 或 Google 账号登录即可。

需要注意，首次订阅**不会回溯历史文章**，只从订阅时刻起收录新内容。这意味着评估候选 KOL 时越早订阅，越能尽快积累起可用于对比的内容样本；确定合作后也应第一时间订阅，避免错过投放文章本身。

## 落地步骤

### 第一步：为候选与已合作的 KOL 建立统一订阅清单

把正在考察、正在合作、以及长期跟踪的 KOL 公众号都加入订阅，具体操作参见[订阅管理指引](/guide/subscription)。清单建议按状态分组（考察中 / 合作中 / 长期观察），方便后续按状态调取数据。

批量订阅可以用 [Open API](/api/) 脚本化完成：

```bash
curl -X POST "https://mp2rss.bugcode.dev/open-api/subscriptions" \
  -H "Authorization: Bearer {feed_key}" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://mp.weixin.qq.com/s?__biz=..."}'
```

### 第二步：持续沉淀内容，替代人工翻页统计

订阅完成后，该号此后的每一篇新文章都会自动进入数据流，团队不再需要定时打开公众号翻看更新。拉取某个号的文章列表时，返回结果带标题、发布时间与 Markdown 正文：

```bash
curl "https://mp2rss.bugcode.dev/open-api/subscriptions/{mpId}/articles" \
  -H "Authorization: Bearer {feed_key}"
```

对考察阶段的候选号，持续积累一段时间后即可统计发文频率、内容类型分布，作为选号依据的一部分；对已合作的号，这份数据本身就是投放留痕——文章标题、发布时间与全文正文都被完整保存，不依赖截图。

### 第三步：横向汇总多个 KOL 的数据做对比

由于每个号的数据结构一致，把多个 KOL 的文章列表按发布时间合并，就能得到一张跨号的内容日历：哪个号在哪天发了什么、投放文章是否按约定时间上线，一目了然。习惯命令行操作的团队成员也可以用 [CLI 工具](/cli/) 直接在终端查看订阅列表与最新文章。

不想写脚本的团队，也可以把每个订阅生成的 RSS / JSON Feed 地址直接导入 Feedly、Inoreader 等阅读器，按时间线浏览所有 KOL 的更新，作为轻量版的日常盯号方式。

### 第四步：合作到期或终止后，档案依然可查

即使后续停止与某个 KOL 合作，已经沉淀下来的历史文章数据依然保留在账号中，可随时调取用于合作复盘或纠纷核对，不需要依赖公众号本身是否还能正常访问。

## 效果对比

| 维度 | 人工翻页 + 截图 | 结构化数据归档 |
| ---- | ---- | ---- |
| 历史内容评估 | 逐条下拉，无法搜索 | 按发布时间检索，可统计频率 |
| 投放留痕 | 截图，丢失排版与链接 | Markdown 全文，含发布时间 |
| 多号对比 | 人工整理表格 | 数据结构统一，可直接合并 |
| 合作结束后可用性 | 依赖原号是否可访问 | 已收录数据长期可查 |

## 常见问题

**订阅 KOL 公众号需要对方授权吗？**
不需要。只需贴入该号任意一篇文章的公开链接即可完成订阅，不涉及对方账号操作，也不需要微信账号登录。

**能查到订阅之前 KOL 发过的历史文章吗？**
不能。首次订阅不回溯历史文章，只从订阅时刻起持续收录新内容，因此考察候选 KOL 或确定合作后应尽早订阅。

**投放文章发布后被 KOL 删除或修改，还能找到原文吗？**
只要文章在被删改前已被收录，对应版本的标题与正文即已沉淀为数据，可随时调取，不受原文章后续变动影响。

**同时跟踪多个 KOL，订阅数量够用吗？**
按套餐档位区分：49 元/月 50 个订阅、99 元/月 100 个、399 元/月 400 个，功能权益完全一致，仅上限不同，详见[会员与计费](/guide/membership)。

**除了公众号，KOL 在其他平台的账号也能一起归档吗？**
支持订阅 X（Twitter）账号，推文与长文同样以结构化数据交付，可以和公众号内容并入同一套归档流程。
