# 订阅管理

Mp2RSS 把 **公众号（MP）** 与 **X（Twitter）账号** 的订阅语义对齐为「订阅 / 取消订阅 / 列表查询 / 内容拉取」，控制台、Open API、CLI 三处用法一致。

## 添加订阅

### 公众号

- **按名称搜索**：输入关键词，从候选中选择订阅；
- **文章链接反查**：贴入任意一篇公众号文章 URL，系统反查并登记订阅。

### X 账号

- **按昵称搜索**：在 Web 控制台输入 X displayName / username 关键字，从候选结果中选定后订阅。

> X 的业务键是 `xUserId` 而非 `@handle` —— handle 可改，`xUserId` 才稳定。X 账号搜索与订阅 / 取消订阅**仅在 Web 控制台提供**，Open API 不暴露这些写类端点；脚本场景请走「Web 控制台完成订阅 → Open API 拉内容」的分工。

## 订阅配额

订阅上限由所购**套餐档位**决定（当前在售 **50 / 100 / 400 个**三档），MP + X 合并计算；同时持有多个未到期会员周期时按最高档生效。详见[会员与计费](/guide/membership)。

## 取消订阅

- **公众号**：`DELETE /open-api/subscriptions/{mpId}` 或 `mp2rss mp remove <mpId>`
- **X 账号**：在 Web 控制台「订阅管理 → X」点击取消订阅。

取消后 Feed 立即停止该源的后续更新。
